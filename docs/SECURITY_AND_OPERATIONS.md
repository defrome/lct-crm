# ИБ и эксплуатация

Документ фиксирует реализованные меры и границы ответственности для требований
`FR-08`, `SOL-10`, `H-SEC-01…06`, трека F. Это не заменяет аттестацию,
моделирование угроз, согласование с владельцем ПДн или документы оператора.

## Матрица ПДн

Согласованный минимальный набор ПДн: ФИО, email и телефон. Поле `position`
контакта является служебным и не включено в минимальный перечень ПДн.

| Набор и место хранения | Цель | Доступ | Защита и журналирование | Хранение |
|---|---|---|---|---|
| `university_contacts.full_name`, `email`, `phone` | Ведение рабочих контактов вуза | `user` в области закреплённых вузов; `manager` и `admin` без ограничения | Контроль области доступа в репозитории; чтение контактов пишет `read_pd`; значения в ORM-аудите маскируются SHA-256 | Срок не согласован; автоматическое удаление отсутствует |
| `import_rows.raw_data`, `parsed_data` | Предпросмотр, проверка и применение строк XLS/XLSX | Пользователь с доступом к задаче импорта | В строках могут быть те же ПДн; строки не попадают в поштучный audit log, итог импорта аудируется | Срок не согласован; повторная валидация жёстко заменяет строки этой задачи |
| Исходный файл импорта в MinIO | Воспроизводимость импорта | Доступ через API приложения и права на задачу | MinIO не публикуется наружу, в БД хранится ключ объекта | Срок не согласован; автоматическое удаление отсутствует |
| Вложения workflow в MinIO | Рабочие документы карточки | Права проверяются по исходной карточке и вузу | Проверка допустимых форматов и размера; скачивание аудируется как `export` | Срок не согласован; soft delete не удаляет объект |
| `audit_log.changes` | Расследование значимых действий | Только `admin` | Append-only триггер PostgreSQL; `full_name`, `email`, `phone` маскируются, IP и user-agent фиксируются как технические данные | Срок не согласован; партиционирование отложено |

## Матрица мер

| Область | Реализовано приложением | Требует инфраструктуры или решения владельца |
|---|---|---|
| Идентификация и доступ | Keycloak JWT, роли `user`/`manager`/`admin`, repository-level scope, запрет dev-auth в `ENV=production` | Реальный realm, корпоративный IdP, MFA и жизненный цикл учётных записей |
| Журналирование | Append-only `audit_log`, аудит отказов, переходов workflow, импорта, чтения ПДн и выгрузок; без открытых ПДн в ORM-аудите | Централизованный сбор, контроль доступа к журналам, срок хранения, резервное копирование |
| Минимизация ПДн | Зафиксирован набор ФИО/email/телефон; остальные поля не добавлять без деловой необходимости | Реестр процессов обработки, правовое основание, согласование сроков хранения |
| Защита данных | Soft delete доменных записей, форматная проверка вложений, закрытый доступ к MinIO через API | Шифрование дисков и резервных копий, управление ключами, DLP/антивирус при изменении требований |
| Сеть | Контейнеры БД, MinIO, Redis и Prometheus не имеют публичных портов в deploy-compose | Межсетевой экран, allowlist LMS/CMS, VPN, корпоративный proxy и mTLS |
| Уязвимости и эксплуатация | Pin-версии контейнеров, CI со статическим анализом и тестами | SCA/сканирование образов, обновления, реагирование на инциденты, независимая оценка соответствия 152-ФЗ и приказу ФСТЭК №117 |

## Закрытый контур

Текущий `docker-compose.deploy.yml` предназначен для тестового сервера и пока
импортирует демонстрационный realm. Его нельзя считать production-конфигурацией
Keycloak до выполнения следующих шагов.

Перед подключением целевого контура администратор должен:

1. Создать production realm Keycloak и клиентов отдельно от
   `docker/keycloak/realm-export.json`; этот файл содержит только локальные
   демонстрационные настройки.
2. Передать секреты через защищённое хранилище или защищённый файл окружения,
   не включаемый в Git: PostgreSQL, MinIO, Keycloak admin, Grafana и токены
   интеграций.
3. Настроить HTTPS на reverse proxy, задать `DOMAIN`, `KEYCLOAK_DOMAIN` и
   `GRAFANA_DOMAIN`; API должен проверять issuer production realm.
4. Отключить общий исходящий интернет. Разрешить исходящие соединения только
   после получения списка IP/CIDR, портов и протоколов LMS/CMS. Пока список не
   передан, `INTEGRATIONS_MODE=fixture`.
5. Проверить маршрут через корпоративный VPN/proxy. Клиентский TLS-сертификат
   завершается на reverse proxy или балансировщике, а не передаётся в код CRM.
6. Оставить MinIO, Redis, PostgreSQL и Prometheus доступными лишь во внутренней
   сети Docker/корпоративном сегменте. Для MinIO не создавать публичный endpoint.

Фактическая проверка в целевом контуре отложена: параметры Keycloak, allowlist,
VPN/proxy и клиентский сертификат пока не предоставлены.

## Кэш и feature flags

Redis/KeyDB используется только для повторного чтения страниц справочников
вендоров, направлений и продуктов. Кэш не содержит ПДн, не обходит проверку
авторизации и не является очередью или офлайн-режимом. После успешной записи
кэш справочников инвалидируется. Ошибка Redis не влияет на ответ API.

Кэш включается только парой `CACHE_ENABLED=true` и
`FEATURE_CACHE_ENABLED=true`. Внешние каналы, уведомления и чат управляются
соответственно `FEATURE_EXTERNAL_CHANNELS_ENABLED`,
`FEATURE_NOTIFICATIONS_ENABLED` и `FEATURE_CHAT_ENABLED`; их значения по
умолчанию `false`. Флаги не изменяют уже сохранённые бизнес-данные.

## Объектное хранилище и перенос файлов

Новые файлы импорта и вложения workflow сохраняются в MinIO; в PostgreSQL
остаются метаданные и `storage_key`. Для старых строк `workflow_attachment_blobs`
запускается команда из каталога `backend`:

```bash
python -m scripts.migrate_attachment_blobs
```

Команда выводит JSON-отчёт, пропускает уже перенесённые объекты и удаляет
исходный blob только после успешной записи в объектное хранилище. До согласования
сроков хранения удалённые в UI файлы и объекты не очищаются автоматически.
Версионирование объектов и антивирусная проверка не требуются. Резервное
копирование MinIO должно быть спланировано отдельно до ввода в эксплуатацию.

## Отложенные работы

- Нагрузочные тесты F1 и утверждение профиля приёмки отложены.
- Партиционирование `audit_log` требует отдельной миграции PostgreSQL и окна
  работ: у существующей таблицы первичный ключ не включает ключ партиции.
- Ретенция `import_rows`, файлов и объектов MinIO ожидает сроков от владельца
  данных.
- Production realm, allowlist интеграций и проверка VPN/proxy/mTLS ожидают
  параметры целевого контура.
