# Архитектура CRM ИТ Школы

Исходная модель Archi — `docs/architecture/CRM-IT-School.archimate`. Её можно
открыть в Archi через **File → Open**.

## Назначение и границы

CRM ведёт взаимодействия ИТ Школы с вузами. Основная карточка связывает вуз,
ИТ-направление и ИТ-продукт; для неё хранятся договор, лицензия, ответственный,
workflow, история и файлы. Система также содержит:

- справочники вузов, контактов, вендоров, продуктов и направлений;
- назначения КАМов и индивидуальную область видимости вузов;
- двухфазный импорт Excel/JSON для восьми типов данных, включая слушателей,
  заявки на обучение и контакты вендоров;
- приём данных LMS и сайта, отчёты, аудит, уведомления, чат и API учебных
  активностей.

Keycloak — источник учётных записей и ролей. PostgreSQL хранит бизнес-данные и
метаданные файлов; MinIO — содержимое файлов. Локальная проекция пользователя
в PostgreSQL нужна для аудита, назначений и связей с доменными объектами.

## Компоненты

```text
Пользователь
    │ HTTPS / same-origin
    ▼
React SPA ── nginx (web) ──► FastAPI (/api/v1, /docs, /metrics)
                                   │       │          │
                                   │       │          └── Prometheus ──► Grafana
                                   │       └── Keycloak (OIDC, JWT/JWKS)
                                   ├── PostgreSQL 16
                                   ├── MinIO (импорт и вложения)
                                   ├── Redis (необязательный кэш)
                                   ├── SMTP / Telegram (необязательные каналы)
                                   └── LMS и CMS Laravel (входящая синхронизация)
```

В local Compose веб-интерфейс доступен на `:5173`, API — на `:8000`, Keycloak —
на `:8080`. В deploy Compose Caddy принимает HTTPS; приложение и Keycloak
работают по одному публичному origin с префиксом `/kc`. PostgreSQL, MinIO,
Redis, Prometheus и Grafana не публикуются наружу.

## Слои приложения

| Слой | Расположение | Ответственность |
|---|---|---|
| Web | `frontend/src` | React SPA, Keycloak Authorization Code + PKCE, клиент API и экспорт из интерфейса. |
| HTTP API | `backend/app/api/v1` | FastAPI-роуты, схемы запросов/ответов, проверка ролей, единый контракт ошибок. |
| Сервисы | `backend/app/services`, `imports`, `integrations` | Бизнес-правила, workflow, импорт, синхронизация, файлы, уведомления и аудит. |
| Доступ к данным | `backend/app/repositories` | Запросы, пагинация, поиск, сортировка и ограничение видимости по вузам. |
| Модель и миграции | `backend/app/models`, `backend/migrations` | SQLAlchemy-модели и Alembic-миграции. |

HTTP-контракты не обходят сервисный слой: импорт и интеграции применяют те же
правила создания и обновления, что и интерфейс. Поэтому повторные загрузки
идемпотентны, а контроль доступа и аудит применяются единообразно.

## Данные и жизненный цикл

Все доменные записи используют мягкое удаление. Изменения фиксируются в
append-only `audit_log`; ПДн в ORM-аудите псевдонимизируются. Файлы импорта,
вложения этапов и чата проходят проверку размера и фактического формата, а
скачивание фиксируется как выгрузка.

Версии workflow изолируют уже начатые карточки от структурных изменений
маршрута. Опубликованная версия не меняет структуру; для изменений создаётся
черновик. Новая карточка может быть поставлена на активный маршрут, после чего
каждый переход сохраняется в истории.

## Опциональные возможности

Возможности ниже выключаются флагами окружения и не влияют на ранее сохранённые
данные:

| Возможность | Условие | Поведение |
|---|---|---|
| Кэш каталогов | `CACHE_ENABLED=true` и `FEATURE_CACHE_ENABLED=true` | Redis кэширует только справочники; при сбое используется PostgreSQL. |
| Чат | `FEATURE_CHAT_ENABLED=true` | Сообщения и вложения внутри карточки. |
| Уведомления | `FEATURE_NOTIFICATIONS_ENABLED=true` | Worker создаёт напоминания и обрабатывает outbox. |
| Внешняя доставка | `FEATURE_EXTERNAL_CHANNELS_ENABLED=true` | Email и Telegram. |

Подробности по эксплуатации и защите данных — в
[`SECURITY_AND_OPERATIONS.md`](SECURITY_AND_OPERATIONS.md), по обмену с LMS/CMS
— в [`INTEGRATIONS.md`](INTEGRATIONS.md).
