## Принятые решения

- ПДн в аудите хешируются HMAC-SHA256 с секретом `AUDIT_HASH_KEY`; в production секрет обязателен.
- Сетевые каналы уведомлений: Telegram и email. Ошибки доставок повторяются через outbox.
- Ответственному отправляется напоминание об отсутствии действия за заданный период; его руководителю — об отсутствии изменения статуса за заданный период. Руководитель хранится в `users.manager_id`.
- Чат поддерживает вложения и упоминания пользователей.
- Реальные интеграционные контракты не предполагаются до передачи API заказчиком.
